# Umriuzoq Rajabov - Shaxsiy Portfolio

Bu loyiha Umriuzoq Rajabovning shaxsiy portfoliosi bo'lib, uning tajribasi, ko'nikmalari va yaratgan veb loyihalarini namoyish etadi. Yosh frontend dasturchi sifatida yaratgan barcha ishlarini shu yerda jamlagan.

## 🚀 Loyiha haqida
Ushbu portfolio zamonaviy frontend texnologiyalari yordamida noldan yaratilgan. Sayt orqali foydalanuvchilar dasturchining shaxsiy ma'lumotlari bilan tanishishi, uning tayyorlagan turli xil loyihalarini (masalan: "Qal'alar jangi", "Ustozlar bayrami", "Mini Mine") ko'rishi va u bilan to'g'ridan-to'g'ri bog'lanishi mumkin.

## 🛠 Texnologiyalar
- **HTML5:** Saytning asosiy strukturasi va tarkibi.
- **CSS3:** Chiroyli dizayn, ranglar (dark mode theme), animatsiyalar va responsiv (telefonlarga mos) ko'rinish.
- **JavaScript:** Sahifani pastga tushirganda (scroll) elementlarning paydo bo'lish animatsiyalari va tugmalar funksionalligi.

## 📱 Xususiyatlari
- **To'liq moslashuvchan (Responsive):** Kompyuter, planshet va telefon ekranlarida birdek chiroyli ko'rinadi.
- **Silliq navigatsiya (Smooth Scroll):** Yuqoridagi menyudagi tugmalar orqali kerakli bo'limlarga silliq o'tish imkoniyati.
- **Animatsiyalar:** Sarlavhada yozuvlarning avtomatik yozilishi (Typing effect) va loyihalar qatorining ajoyib chiqib kelishi.
- **Jonli aloqa:** Google Meet va Telegram orqali bitta tugma bilan aloqaga chiqish imkoniyati.

## 💻 Qanday ishlatiladi?
1. Loyiha papkasiga kiring.
2. `index.html` faylini istalgan zamonaviy brauzerda (Google Chrome, Edge, Yandex) ustiga ikki marta bosish orqali oching.
3. Hech qanday qo'shimcha server, Node.js yoki boshqa dastur o'rnatish talab etilmaydi! Faqat toza HTML, CSS va JS.
